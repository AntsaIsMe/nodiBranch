# Design System

## Palette
- **Text**: `#191f34` (Deep Navy)
- **Background**: `#ffffff` (White)
- **Primary**: `#1d5f62` (Marine Teal)
- **Secondary**: `#c6eabe` (Soft Mint)
- **Accent**: `#8aba82` (Seafoam Green)

## General Rules
- **No Emojis**: Strictly forbidden in design and code.
- **Simplicity**: Minimalist, clean, professional.
- **Consistency**: Use the primary palette for all core UI elements.
- **Responsiveness**: Mobile-first approach.
- **Accessibility**: High contrast for text against background.
