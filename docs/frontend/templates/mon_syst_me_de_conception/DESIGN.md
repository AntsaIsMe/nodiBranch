# Design System

## Brand & Style
The design system adopts a **Modern / Fidelity** aesthetic, characterized by clean lines, precise structural layout, and high clarity. The tone is reliable, professional, and accessible.

## Colors
- **Primary:** `#ffffff`
- **Secondary:** `#1d5f62`
- **Tertiary:** `#c6eabe`
- **Neutral:** `#8aba82`
- **Mode:** Light

## Typography
Global font family: **Inter**
- **Headlines:** Bold and legible at large scales.
- **Body:** Optimized for readability at 16px base size.
- **Labels:** Clear and compact UI indicators.

## Layout & Spacing
Built on a proportional spacing scale (`2`) with standard gutters and responsive margins, ensuring consistent breathing room across all viewports.

## Elevation & Depth
Subtle tonal layers and minimal ambient shadows create gentle separation and visual hierarchy.

## Shapes
Components feature a moderate **roundedness** level (`2`), offering smooth, approachable corners (0.5rem base radius).

## Components
Consistent styling applied to buttons, input fields, cards, and chips using the design system's tokenized color and shape rules.
