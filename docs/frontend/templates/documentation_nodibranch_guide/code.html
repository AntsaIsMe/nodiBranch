Installation & Quickstart

Get up and running with Nodibranch in under two minutes. Nodibranch marries the declarative architectural elegance of Symfony with the asynchronous speed and type inference of modern TypeScript.

terminal Prerequisites

Before initializing your service, verify your local runtime. Nodibranch is optimized for Node.js LTS, but runs seamlessly with modern package managers and alternative runtimes like Bun.

Node Runtime >= 18.0.0 LTS Active maintenance
TypeScript 5.0 or Higher Legacy & 5.4 Decorators
Package Manager npm / pnpm / bun Lockfile compatible
tips_and_updates
Fast-track via CLI generator

Rather than installing manually, run npm create nodibranch@latest to bootstrap an opinionated bundle with routing, Prisma ORM, and Jest preconfigured.

1 Install Dependencies

Production + Dev Packages

Install the core bundle and its required metadata reflector into your project:

$ npm i nodibranch @nodibranch/core reflect-metadata
$ pnpm add nodibranch @nodibranch/core reflect-metadata
$ yarn add nodibranch @nodibranch/core reflect-metadata
$ bun add nodibranch @nodibranch/core reflect-metadata
info
Symfony Developer Note

Nodibranch uses TypeScript experimental decorators and reflect-metadata to deliver Symfony-identical autowiring without needing XML or YAML service definitions.

2 Configure tsconfig.json

Because Nodibranch relies on design-time parameter reflection for dependency injection, you must enable metadata emission in your compiler flags.

warning
Compiler Settings Required

Ensure "experimentalDecorators": true and "emitDecoratorMetadata": true are enabled in your tsconfig.json, otherwise constructors will fail to resolve dependencies.

tsconfig.json JSON 
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "commonjs",
    "moduleResolution": "node",
    "experimentalDecorators": true,        // Required for Nodibranch attributes
    "emitDecoratorMetadata": true,         // Required for Constructor Autowiring
    "strict": true,
    "esModuleInterop": true
  }
}

3 Creating Your First Controller

Controllers handle incoming HTTP queries. Services declared in the constructor parameter signature are automatically autowired by the Marine DI container.

code src/controllers/api.controller.ts TS 
import { Controller, Get, Inject } from 'nodibranch';
import { HealthService } from './services/health.service';

@Controller('/api/v1')
export class ApiController {
  constructor(
    // HealthService is resolved automatically via Service Autowiring
    private readonly healthService: HealthService
  ) {}

  @Get('/health')
  public check() {
    return this.healthService.getStatus();
  }
}

4 Bootstrapping the Server

Initialize the runtime kernel with NodibranchFactory.create(). This compiles the autowired service container and mounts the HTTP request pipeline.

play_circle src/main.ts TS 
import 'reflect-metadata';
import { NodibranchFactory } from 'nodibranch';
import { AppModule } from './app.module';

async function bootstrap() {
  // Creates kernel, compiles container pass, and boots pipeline
  const app = await NodibranchFactory.create(AppModule, {
    cors: true,
    logger: ['log', 'error', 'warn'],
  });

  const port = process.env.PORT || 3000;
  await app.listen(port);
  console.log(`Nodibranch kernel active on http://localhost:${port}`);
}

bootstrap();
